> I THOROUGHLY enjoy this Salvadoran (Purple) Pacamara from Gringo Nordic. VERY plum-y, and very "purple" in taste overall.

## About the coffee
- **Origin:** 🇸🇻 El Salvador
- **Variety:** Pacamara
- **Process:** Washed
- **Roast level:** Light
- **Tasting notes:** Orange Marmalade / Creamy / Plum

## Brewing recipe

- **Equipment:** Hario Switch.
- **Dose:** 20 g (0.71 oz)
- **Water:** 320 g (11.29 oz)
- **Ratio:** 1 : 16
- **Grind:** 19 clicks on Timemore C2 Max.
- **Water temperature:** 94 °C (201 °F)
- **Total brew time:** 3:00-3:20



|   Time    | Instruction                                                                                                            | Pour | Total |
| :-------: | ---------------------------------------------------------------------------------------------------------------------- | ---- | ----- |
|       | Rinse filter thoroughly and preheat brewer.                                                                                    |      |       |
| **0:00-0:45** | Bloom with **60 g**, swirl once at **0:10**. Make sure to use enough agitation.                                        | 60g  | 60g   |
| **0:45-1:15** | Pour to **170 g** in slow concentric spirals.                                                                          | 110g | 170g  |
| **1:15-1:45** | Pour to **250 g**. Keep slurry height moderate, avoid aggressive center dumping.                                       | 80g  | 250g  |
| **1:45-2:05** | Pour to **320 g**                                                                                                      | 70g  | 320g  |
|   **2:05**    | Gentle swirl to flatten the bed.                                                                                       | 0g   | 320g  |
|   **3:20**    | Drawdown should finish
